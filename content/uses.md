People ask what I work on. This is the short answer.

## Hardware

My daily driver is a Windows 11 Pro laptop. BitLocker on, Defender on, 32GB of RAM so Hyper-V labs actually run. The lab itself is a retired desktop: domain controller, file server, an Ubuntu jump box. Nothing fancy. It works.

Field bag: cable tester, console cable, a spare access point. Wi-Fi problems don't fix themselves, and they never happen next to your desk.

## Software

VS Code, Windows Terminal, RSAT, Graph Explorer, Wireshark. Veeam Agent for the backups nobody thinks about until they need them.

## Network & SOPs

Documented onboarding/offboarding checklists, Intune compliance baselines, and backup-restore drills. Solved problems get written down — see the [Knowledge Base](/knowledge/) for field-tested guides.
